# Contributing

The project is at the design stage and has no engine code yet, so open an issue before starting larger work.

1. Fork the repo and create a branch.
2. Run `pnpm install`, make the change, then run `pnpm preflight`.
3. Open a pull request with a [Conventional Commit](https://www.conventionalcommits.org) title.

Examples must use invented data, never real contracts, client names or personal data.
